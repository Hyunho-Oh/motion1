# 한 해의 끝에 — 연말 키네틱 타이포그래피

10초 분량의 세로형 연말 모션그래픽입니다. 한 해를 천천히 돌아보고 새해를 따뜻하게 맞이하는 마음을 한국어 키네틱 타이포그래피, 눈발, 금빛 조명으로 표현했습니다.

## 파일

- `year_end_kinetic_typography.avi` — 9:16 세로 영상(540 × 960), 배경음악 포함
- `year_end_kinetic_typography.gif` — 애니메이션 미리보기
- `year_end_kinetic_typography.html` — 브라우저에서 재생하는 인터랙티브 버전
- `year_end_carol.wav` — 직접 합성한 캐럴풍 배경음악(스테레오, 10초)
- `make_motion.py` — 영상과 오디오 제작 스크립트

## HTML 재생

HTML 파일과 WAV 파일을 같은 폴더에 둔 상태로 `year_end_kinetic_typography.html`을 브라우저에서 엽니다. 장면은 자동으로 전환되며, 아래 플레이어에서 배경음악을 재생할 수 있습니다. `다시 재생` 버튼은 타이포그래피 장면을 처음부터 다시 시작합니다.

HTML은 브라우저 재생용이고, AVI에는 음악이 포함되어 있습니다.
